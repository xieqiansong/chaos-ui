## 🥇 第一梯队：几乎每个后台都有（先做这 8 个）

### 1. 搜索表单 + 表格 + 分页（三位一体） ✅️
**这是后台的“心脏”，90% 的页面都是这个结构。**

你要实现：
- 顶部搜索区：输入框、下拉选择、日期范围
- 搜索/重置按钮
- 中间表格：列定义、数据渲染
- 底部分页：页码、每页条数、总数
- 请求时带 `loading`，搜索时回到第 1 页

**关键点：**
```
查询参数 = { page, pageSize, ...搜索条件 }
响应 = { list, total }
```
搜索条件变化 → 重置 page=1 → 重新请求。

---

### 2. 新增 / 编辑 弹窗表单 ✅️ ✅️
**频率仅次于列表页。**

你要实现：
- 点“新增”打开空表单
- 点“编辑”打开表单并回填数据
- 表单校验（必填、格式、长度）
- 提交后关闭弹窗、刷新列表、弹出成功提示
- 新增和编辑复用同一个弹窗组件

**关键点：**
- 用 `v-model` 控制弹窗显示
- 用 `ref` 拿表单实例调 `validate()`
- 用一个 `isEdit` 或 `row.id` 判断模式

---

### 3. 删除确认 + 批量删除 ✅️
**每个 CRUD 都有。**

你要实现：
- 单行删除：`ElMessageBox.confirm` 二次确认
- 多选：表格加 `selection` 列
- 批量删除：收集选中 id，调接口
- 删除后刷新列表，如果当前页删空了要回退一页

**关键点：**
- `ElMessageBox.confirm` 返回 Promise
- 表格 `@selection-change` 拿选中行

---

### 4. 请求封装 + 统一错误处理 ✅️
**不做这个，后面每个页面都会重复造轮子。**

你要实现：
- `axios.create()` 创建实例，配 `baseURL`、超时
- 请求拦截器：自动带 token
- 响应拦截器：统一处理 `code !== 0`、401 跳登录、网络错误提示
- 封装 `get/post/put/delete` 方法
- 泛型让返回值有类型

**关键点：**
```ts
// 让调用方拿到的是 data 而不是 AxiosResponse
service.interceptors.response.use(res => res.data)
```

---

### 5. 路由 + 菜单 + 布局框架 ✅️
**没有这个，页面没法组织。**

你要实现：
- 左侧菜单（`el-menu`）+ 顶部 + 内容区（`router-view`）
- 路由配置：`path`、`component`、`meta.title`、`meta.icon`
- 菜单根据路由自动生成
- 点击菜单跳转，当前路由高亮
- 面包屑

**关键点：**
- 布局用嵌套路由：`Layout` 作为父路由
- `meta` 存菜单元信息

---

### 6. 登录 + Token + 路由守卫 ✅️
**权限的入口。**

你要实现：
- 登录页：账号密码表单
- 登录成功存 token 到 Pinia + localStorage
- 路由守卫：没 token 跳登录
- 请求拦截器自动带 token
- 退出登录清 token

**关键点：**
- `router.beforeEach` 做守卫
- Pinia 的 state 刷新会丢，所以要同步 localStorage

---

### 7. 加载状态 + 空状态 + 错误状态 ✅️
**让页面“像个产品”的关键细节。**

你要实现：
- 表格 `v-loading`
- 按钮提交时 `loading`，防重复点击
- 空数据用 `el-empty`
- 请求失败展示错误提示或重试按钮

---

### 8. 消息提示统一封装 ✅️
**`ElMessage` / `ElMessageBox` / `ElNotification` 到处用，封装一下更规范。**

你要实现：
- `showSuccess`、`showError`、`showWarning`
- 确认框封装成 Promise 风格
- 避免每个文件都 import 一堆

## 🥈 第二梯队：大部分后台都有（再做这 8 个）

### 9. 表单高级用法 ✅️
- 动态表单（字段从配置生成）
- 联动：A 变化 → B 的选项/禁用状态变化
- 自定义校验规则
- 表单分组 / 分步表单

### 10. 表格高级用法 ✅️
- 列宽、固定列、排序
- 自定义列模板（状态标签、操作按钮）
- 格式化：日期、金额、枚举转文字
- 行展开、树形表格
- 列显示/隐藏控制

### 11. 枚举 / 字典统一管理 ✅️
**企业里到处都是状态码。**

你要实现：
- 一个字典配置：`{ 1: '启用', 0: '禁用' }`
- 一个 `<DictTag>` 组件，传 value 显示对应文字和颜色
- 下拉选项也从这个字典生成

### 12. 文件上传 ✅️
- 单文件、多文件
- 图片上传 + 预览
- 上传进度
- 限制格式和大小
- 配合表单提交（先传文件拿 URL，再提交表单）

### 13. 导出 Excel / 导入 ✅️
- 前端导出：`xlsx` 库
- 后端导出：请求返回 blob，前端下载
- 导入：上传文件，后端解析

### 14. 图表 ECharts 封装 ✅️
- 封装一个 `<BaseChart>` 组件
- 传入 `option` 自动渲染
- 监听容器 resize 自适应
- 组件卸载时 `dispose`
- 常用图表：折线、柱状、饼图

### 15. 详情页 ✅️
- 描述列表 `el-descriptions`
- 分区展示
- 从列表页跳转带 id
- 返回按钮

### 16. 权限控制（按钮级） ✅️
- 用 Pinia 存用户权限码
- 自定义指令 `v-permission`
- 没权限的按钮不渲染或禁用
